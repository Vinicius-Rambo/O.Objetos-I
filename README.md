## Orientação a Objetos I  

**Componente Curricular**: Orientação a Objetos I  
**Semestre**: 2º  
**Carga horária**: 80h (67h relógio)
**Professor:** Humberto Martins Beneduzz

---
## Objetivo

Propiciar a compreensão dos principais aspectos do **paradigma de desenvolvimento de software orientado a objetos** e implementar esses conceitos em uma linguagem de programação (Java).

---
## Ementa

- O paradigma Orientado a Objetos
- Conceitos fundamentais: classe, objeto, atributo e método
- Encapsulamento e herança
- Associação (agregação e composição)
- Polimorfismo e interfaces
- Aplicação dos conceitos em uma linguagem de programação
